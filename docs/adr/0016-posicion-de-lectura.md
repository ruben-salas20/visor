# 0016. Posición de lectura al ocultar una pestaña

**Estado:** Aceptada

## Decisión

Al ocultar una pestaña se le pide su posición: en las notas, la línea del Markdown y la altura, como al alternar con el editor. De paso se le pide guardar el texto pendiente del editor. Si la pestaña se descarga, se recoloca al recargarla. Rust solo guarda los números, porque la página puede ser una web.
