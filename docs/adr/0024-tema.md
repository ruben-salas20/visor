# 0024. Tema de Omarchy

**Estado:** Aceptada

## Contexto

Las páginas deben seguir el tema del escritorio.

## Decisión

El tema se lee de `~/.local/state/omarchy/current/theme/colors.toml` y se vigila esa carpeta. Las páginas reciben `--visor-*` como hoja de estilo de usuario, que su propio CSS siempre puede sobrescribir. `fc-match` (fuente monoespaciada) corre aparte porque tarda ~20 ms. La transparencia de la ventana la decide el usuario en Hyprland.

## Consecuencias

Fuera de Omarchy las variables no existen; las páginas deben dar un valor de reserva.
