# 0024. Tema de Omarchy

**Estado:** Aceptada

## Decisión

Las páginas siguen el tema del escritorio. Se lee `~/.local/state/omarchy/current/theme/colors.toml` y se vigila esa carpeta. Las páginas reciben `--visor-*` como hoja de estilo de usuario, que su CSS siempre puede sobrescribir. `fc-match` (fuente monoespaciada) corre aparte porque tarda ~20 ms. La transparencia de la ventana la decide el usuario en Hyprland. Fuera de Omarchy las variables no existen: las páginas dan un valor de reserva.

La persona puede forzar «Claro» (paleta White de Omarchy) u «Oscuro» (Matte Black) en Ajustes. Esas dos paletas van dentro del binario, porque fuera de Omarchy no hay tema que leer. «Sistema» es el comportamiento anterior.
